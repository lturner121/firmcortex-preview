# FirmCortex design preview

The single approved FirmCortex website preview, hosted on GitHub Pages.
Approved copy updated 16 November 2026 for desktop and mobile.

- Preview: https://lturner121.github.io/firmcortex-preview/
- All displayed companies and figures are invented.
- The demo form is a design preview and does not submit information.
- Privacy and terms pages are drafts with placeholders.

## Update the preview

Edit the HTML, CSS, JavaScript or supplied assets and push to `main`.
GitHub Pages publishes the repository root. `.nojekyll` keeps the files
as supplied; no build step is required.

This repository contains only the public website files, with a fresh
history. It does not include the application, private project material
or the former host's deployment configuration.

The initial import matches the approved preview from 15 November 2026
(source commit `3a66fa3536966f7e5566da4960ac2916d7d70eb7`).
